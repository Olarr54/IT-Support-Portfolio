# Example Service Desk Ticket

## Incident

**Ticket ID:** INC-001

**Title:** User unable to access Microsoft Teams

**Category:** Application

**Priority:** Medium

**Status:** Resolved

## User Report

The user reports that Microsoft Teams is not opening correctly.

## Initial Investigation

I would establish:

- When the issue started
- Whether Teams previously worked
- Whether other Microsoft 365 applications work
- Whether other users are affected
- The exact error message

## Troubleshooting

1. Checked the user's network connection.
2. Confirmed the issue was limited to Microsoft Teams.
3. Restarted the application.
4. Restarted the computer.
5. Checked for available updates.
6. Tested the application again.

## Resolution

The application was successfully reopened and tested.

The user confirmed that Teams was functioning normally.

## Documentation

The troubleshooting steps and resolution would be recorded within the service desk ticket.

## Escalation

If the issue could not be resolved at first-line level, I would record all troubleshooting completed before escalating to the appropriate support team.
